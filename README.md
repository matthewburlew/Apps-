# Baseball Memorabilia Tracker & Valuation Tool

## Student Name
Matthew Burlew

## App Description
This app helps baseball memorabilia collectors catalog, track, and estimate the value of their collections. Users can log items, view estimated valuations, and generate insurance reports — making it easy to manage high-value collections like signed cards, bats, and jerseys.

## Intended Users
This app is intended for baseball memorabilia collectors, sports card investors, and insurance professionals who need organized, up-to-date valuations of collectible items.

## Planned Features
- Item catalog with details (player, item type, condition, purchase price)
- Automated value estimation using recent sales data
- PDF insurance valuation report generator
